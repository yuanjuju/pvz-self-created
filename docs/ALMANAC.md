## 僵尸来客

| 类别 | 代码中的主要差异 |
| --- | --- |
| 普通僵尸 | 基础移动与啃咬 |
| 摇旗僵尸 | 波次生成时先出场 |
| 路障僵尸 / 铁桶僵尸 | 不同生命值 |
| 橄榄球僵尸 | 更快的移动与较高生命值 |
| 铁门僵尸 | 护盾状态与减速处理 |
| 读报僵尸 | 报纸破损后改变移动 / 攻击表现 |
| 撑杆僵尸 | 遇到可跨越植物时跳跃 |
| 舞王僵尸 / 伴舞僵尸 | 召唤与被召唤角色 |
| 小丑僵尸 | 延迟后概率触发爆炸 |

`ZombieType` 枚举共有 11 种。摇旗与伴舞的出场方式不同于普通随机生成，不能把全部枚举数量理解为每波都出现的种类数。
