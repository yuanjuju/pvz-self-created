# PLAYER ONE · 操作手册

[回到草坪](../README.md) · [植物图鉴](ALMANAC.md) · [编译运行](BUILD.md)

本页按 `fengmian.cpp`、`Game.cpp` 和 `Store.h` 的当前分支整理。游戏本体为 Windows 字符控制台，使用键盘输入和控制台颜色显示。

## 开场与模式

`main.cpp → game_begin()` 显示封面与菜单。可进入背景对话、游戏菜单及设置。当前游戏菜单提供无尽模式与植物 / 僵尸说明；无尽模式随后进入 `Game::init()` 和 `Game::loop()`。

旧 README 提到的存档、多关卡、破瓦罐和传送带属于历史描述，目前没有从现有入口确认对应完整实现，不列入本版可玩功能清单。原说明保留于[档案](archive/README.original.md)。

## 选卡、落子、铲除

| 按键 | 所处状态 | 行为 |
| --- | --- | --- |
| `1`–`9` | 普通 / 种植 | 选择前 9 张植物卡 |
| `A` / `B` / `C` | 普通 / 种植 | 选择土豆地雷 / 地刺 / 高坚果墙 |
| `↑ ↓ ← →` | 种植 / 铲除 | 在草坪网格移动焦点 |
| `Enter` | 种植 | 尝试购买并放置；成功才扣阳光、开始卡牌冷却 |
| `X` | 普通 | 进入铲除模式 |
| `Enter` | 铲除 | 尝试铲除当前位置，然后退出焦点 |
| `Esc` | 种植 / 铲除 | 取消操作，回到普通状态 |
| `Space` | 游戏过程中 | 暂停；再次按空格继续 |

目前铲除函数 `Game::delPlant()` 的坐标检查存在横纵坐标混用问题，可能导致右侧列无法铲除；这里记录实际限制，未将操作表当作完整玩法测试报告。

## 阳光与出场

草坪可种植区域为 **7 列 × 5 行**。代码额外保留右侧一列用于僵尸入场。商店初始阳光为 **200**，购买条件为阳光足够、卡牌冷却完成且目标格可种植。

主循环根据计数器推进植物、僵尸、商店、子弹、清理与重绘。`SLEEP_TIME=100` 表示每轮附加 100 ms 等待，实际更新频率还受到逻辑和控制台输出耗时影响。

## 开发时的快捷键

- `+`：增加 1000 阳光，同时落入后续分支刷新所有植物冷却。
- `*`：仅刷新植物冷却。

这些快捷键原本就在代码中，用于调试。它们没有作为新增功能实现。

## 手动试玩检查

Windows 构建成功后仍需在真实控制台依次确认：封面文字、菜单跳转、种植和扣费、卡牌冷却、暂停恢复、僵尸入场、子弹碰撞、失败退出、音效播放。CI 只执行编译和资源到位检查，不模拟这些交互。
