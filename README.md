# PVZ自创

#### 介绍
基于c++开发的一款高仿版植物大战僵尸，采用简洁的画风实现植物大战僵尸的动画。

### 基本框架

#### UI设计

- 封面
  - 需要有字符画的参与，标明游戏名称、制作团队、游戏模式选择选项、设置选项（是否关闭音乐、是否调取存档）
- 背景叙述（若读取存档这一步跳过）
  - 需要有僵王博士和戴夫的符号画出现，出现交谈画面，叙述游戏的故事背景
- 选择关卡（菜单页面）
  - 需要显示每一关的字符画，然后标明关卡标题和序号
  - 玩家输入选中后应该出现提示音
  - 页面属性应该包含已获金币总量，等级，商店的入口
  - 页面属性也应当包含僵尸和植物的说明入口，标明各种僵尸的弱点和特点，标明各种植物的特点，伤害，阳光需求度，恢复度。
- 地图设计
  - 整体以矩形为基本框架，适当作出一些变化，比如某一行缺失几个方块
  - 破瓦罐模式，只需要将右一半矩形设成阴影即可，可以使用与地图边框不一样的颜色
  - 破瓦罐模式和传送带模式都需要下方卡槽的设计
- 商店
  - 将商店展示在游戏界面下方，将植物卡片以及对应的价格罗列在下方两排，阳光显示在卡片上方，每隔一段时间阳光自动增加25，同时添加两种不同的游戏进程（游戏中和暂停）分别对应显示两种简要说明，玩家可以选择暂停后，选择进入商店进行交易，商店的布局可以借用地图的框架，只是在每一个方格块放置商品，并且标明价格和数量，如果布局允许的的话，可以适当加入一些字符画，戴夫之类的

#### 子弹系统

- 子弹系统可以视作植物和僵尸战斗系统的桥梁，由植物的战斗系统触发后，检测是否击中僵尸，其中元素应当包含子弹的颜色、攻击力、是否越过格子边界，是否击中僵尸
  
#### 战斗实时显示系统

- 该系统用于显示一个格子当中的实时信息，如植物的名称，植物的hp，僵尸的数量，僵尸的hp，僵尸的名称。
- 这个系统应当还包含接收键盘输入，对格子进行左右上下选择或选中，支持植物的种植和铲除

#### 战斗系统

- 僵尸战斗系统
  - 每一种僵尸可以看作一个子类，继承自原始基类，基类包含着各个僵尸共同的属性，包括但不限于生命值HP，移动速度，攻击速度。而每个僵尸的弱点和特点将在于各自的子类中呈现。且每个类的构造函数创造时，各项指标默认为顶格。
- 植物卡牌系统
  - 同理，每一种植物也可以参照僵尸，继承自原始基类，基建包含着各个植物的共同的属性，包括但不限于生命值HP，攻击速度，需求阳光量，冷却时间，最重要的是是否处于选中状态，是否被吃

#### 商店系统

- 商店中应该是一个基类中派生出去多个子类，每一个子类对应一种商品，基类中应当包含商品的各种属性，例如价格、属性说明、数量。其中属性说明可以用纯虚函数进行占位，在每一个子类中进行实现。

#### 游戏运行维持系统

- 该系统的主要作用是控制阳光量的生成，金币的掉落，游戏中的人物交谈，植物的冷却后的生成，最重要的是链接植物和僵尸的战斗系统，实现双方的交互。
- 阳光量的生成可以按照时间来控制，也可以按照僵尸的剩余量来实时控制
