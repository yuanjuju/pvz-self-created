# PVZ 自创版 — Plants vs. Zombies 复刻

## 项目简介

基于 C++ 开发的一款高仿版植物大战僵尸，采用简洁画风实现植物大战僵尸的核心玩法与动画效果。

## 游戏框架

### 游戏流程

1. **封面** — 游戏名称、制作团队、模式选择、设置选项（音乐/存档）
2. **背景故事** — 戴夫与僵王博士的对话，交代故事背景
3. **关卡选择** — 关卡字符画展示，提示音反馈，金币/等级/商店入口
4. **地图对战** — 以矩形为基本框架的地图设计，含破瓦罐模式和传送带模式
5. **商店系统** — 游戏内商店，购买植物和道具

### 核心类

| 类 | 说明 |
|---|---|
| `Game` | 游戏主逻辑，管理游戏循环与状态 |
| `Map` | 地图网格与布局管理 |
| `Plant` | 植物类（豌豆射手、向日葵等） |
| `Zombie` | 僵尸类（普通僵尸、路障僵尸等） |
| `Bullet` | 子弹类，处理攻击与碰撞 |
| `Store` | 商店系统，管理购买逻辑 |
| `ui_tools` | UI 工具函数，辅助界面绘制 |

## 编译运行

使用支持 C++ 的编译器打开项目，配置好相关依赖后编译运行即可。

## 资源说明

游戏包含完整的音效资源（攻击、背景音乐、游戏结束等），增强游戏体验。
